The steps to run this project.
Step 1 (Most IMP) :- You needed to install python and node.js.
Step 2 :- After downloading the repository, unzip all files and open the main folder in vs code ( or any of your coding platform).
step 3 :- Once opened, go to terminal tab and open new terminal -> In terminal you need to install all the required libraries by insterting command -> pip install -r requirements. txt.
step 4 :- After installation completes, Run train_model.py.
step 5 :- After successfully completing model training, run main python file app.py.
Step 6 :- It will show you 2 links open upper link of localhost.
Step 7 :- It will redirect you to your browser window where you can run actuall project.
